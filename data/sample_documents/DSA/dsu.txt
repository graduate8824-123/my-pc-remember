Disjoint Set Union (DSU) / Union-Find Data Structure

Summary:
Disjoint Set Union is a data structure that tracks a set of elements partitioned into a number of disjoint (non-overlapping) subsets. It provides near-constant-time operations to add new sets, merge existing sets, and determine whether elements are in the same set.

Key Optimizations:
1. Path Compression: Flattens the structure of the tree by making every node point directly to the root when find() is called.
2. Union by Rank / Size: Always attaches the smaller tree to the root of the larger tree during union().

Combined Complexity:
With both path compression and union by rank, any sequence of m operations on n elements takes O(m * alpha(n)) time, where alpha is the inverse Ackermann function (effectively <= 4 for all practical values).

Applications:
- Kruskal's algorithm for finding the Minimum Spanning Tree (MST).
- Detecting cycles in undirected graphs.
- Dynamic graph connectivity queries.
