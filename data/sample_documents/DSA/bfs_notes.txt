Breadth-First Search (BFS) and Graph Traversal Notes

Overview:
Breadth-First Search is an algorithm for traversing or searching tree or graph data structures. It starts at the tree root (or some arbitrary node of a graph) and explores all of the neighbor nodes at the present depth prior to moving on to the nodes at the next depth level.

Queue Data Structure:
- Standard FIFO Queue is used.
- Nodes are marked visited upon discovery to avoid infinite loops in cyclic graphs.

Shortest Path Property:
- For unweighted graphs, BFS is guaranteed to find the single-source shortest path in terms of minimum number of edges.
- Contrast with Dijkstra's algorithm which handles non-negative weighted graphs using a priority queue.

Time Complexity: O(V + E)
Space Complexity: O(V) for the queue and visited array.

Common Applications:
1. Finding connected components in an undirected graph.
2. Finding the shortest path between two vertices in an unweighted graph.
3. Level-order tree traversal.
4. Bipartite graph testing (2-coloring).
